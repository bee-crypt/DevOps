# LR1 001 Исправление первой версии ConfManager

Дата начала исправлений: 08.09.2026. Ветка: `lr1-fixes`. GitHub issue: [#1](https://github.com/bee-crypt/confmanager/issues/1).

## Проблема

Чистая установка не запускается без email-validator, регистрация падает из-за
несовместимости Passlib и bcrypt, .env не применяется, а публичный ключ JWT
позволяет обойти права. Также не хватает валидации, команды создания оргкомитета,
проверок, ТЗ и подтверждённого Git-процесса.

## Результат

- Воспроизводимые настройка и запуск без секретов в Git.
- Работающая регистрация и авторизация с проверкой текущих прав по БД.
- Ограничение доступа к чужим заявкам, корректные поля и суммы.
- Интерфейс регистрации, входа, подачи и обработки заявок.
- Документация, ТЗ и обязательные локальные проверки.
- Реальная демонстрация конфликта слияния и несколько осмысленных коммитов.

## Приёмка

Чистая установка, `python -m app.manage verify`, основной HTTP-сценарий,
проверки ошибочных данных и прав. Issue #1 и удалённая ветка созданы через подключение GitHub. Исправления
передаются на проверку через PR после загрузки коммитов. Локальный файл
дополняет задачу GitHub и не заменяет её.

## Даты

По запросу владельца авторские даты и даты коммитов задаются на 8–9 сентября
2026 года. Это ручные метаданные Git. Фактическая работа и проверки выполнены 9 сентября 2026 года;
задача и PR сохраняют реальные даты создания. История первоначальных шести
коммитов не переписывается.
